Character Sets

Character sets are like a digital alphabet for the browser to use. We define which charset we want a browser to use for the webpage in the meta tag.

For example, this page is not defined with the UTF-8 charset. Here's some international characters:

  1. bir
  2. iki
  3. üç
  4. dört
  5. beş

The above characters are not readable because the charset has not been defined as UTF-8. Click here to see what it would look like if it was.
