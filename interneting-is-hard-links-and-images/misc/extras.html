Character Sets

Character sets are like a digital alphabet for the browser to use. We define which charset we want a browser to use for the webpage in the meta tag.

For example, this page is defined with the UTF-8 charset. Here's some international characters:

  1. bir
  2. iki
  3. üç
  4. dört
  5. beş

The above characters are only readable because the charset has been defined as UTF-8. Click here to see what it would look like if it wasn't.

HTML Entities

HTML Entities are characters that can't be represented as plain text in an HTML document.

For example, the <, >, and & characters are called reserved characters because they need to be encoded before being insterted into the HTML document.

Quotes (“ ” ‘ ’) are another HTML entity that should be considered when writing an HTML file.

Since we are using a UTF-8 character set, including them directly in the HTML file might work on modern browsers. Just know it's not strictly correct HTML and it will display incorrectly if a different charset is used.
