JPGs

JPGs handle large colour palettes without massive file size. Ideal for things with lots of gradients in them, like photos.

However they don't allow transparent pixels, so you will see a white background/edges for example.

GIFs

GIFs are useful for simple animations, but you can't have semi-opaque pixels and they have colour palette limitations so they can't have much detail.

PNGs

PNGs are ideal for things that aren't photos and aren't animated. They have larger file size but can deal with opacity just fine and without colour palette limitations.

These image file types are Ideal for icons, diagrams, logos, etc.

SVGs

SVGs are vector based, not pixel based. This means they can be scaled up/down to any dimension without loss of quality.

SVGs are ideal for responsive design.

These image file types are great for icons/diagrams/logos or any other use-case that PNGs are suitable, and they should be used whenever possible.
