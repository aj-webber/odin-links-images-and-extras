Links

This page is about links, click here for the images page.

There are three kinds of links:

  • Absolute Links - Scheme, Domain, and Path of the target defined. These can link to anywhere including our own files, but it's better to Use for external resources to avoid complications.
  • Relative Links - These point to another resource on our website with respect to the file they are defined in. Best used for linking to files/resources in the same folder or same area of a website.
  • Root-Relative Links - Like Relative Links, but link with respect to the root of the entire website. They start with a "/" and even if the relative location of this current page changes, any resource it Root-Relative Links to will work. Since this page isn't hosted on a server, they're no use currently.
